The UAT Outcome table MUST list every must-have FR with a definitive Pass / Fail / Conditional outcome. Empty rows are NOT allowed.

The Stakeholder Decisions table MUST have a row for every required signer (Sponsor, Product Owner, Technical Lead at minimum) with: Stakeholder name, Role, Decision (Approve/Approve-with-conditions/Reject), Conditions, Date, Signature reference (e-sig URL, ticket ID, or scanned PDF reference). NO row may have an empty Decision.

The Conditions table MUST list every conditional-pass condition with: Condition, Stakeholder who set it, Required action, Target deadline.

The v8 Prerequisites section MUST exist even if empty (an empty list is a valid signal: "no preconditions; deploy when ready").
