## Purpose

This router reduces context pressure by delegating stack-specific instructions to focused sub-skills while preserving the original entrypoint path.

## Dispatch Workflow

### Step 1: Load shared core

Load `unit_test_subskills/security_unit_test_shared_core_skill.md`.

The shared core defines:
- Discovery and convention rules
- Coverage assessment approach
- Generic test-writing constraints
- Framework selection fallback
- Output/report requirements

### Step 2: Detect stack signals

Detect these markers in the repository:

- **Node/Express backend**
  - `express` dependency
  - route definitions (`router.get`, `router.post`, `app.use`, etc.)
- **Frontend SPA (Vue/React)**
  - `vue`, `react`, `vite`, `pinia`, frontend auth/store code
- **Supabase BaaS**
  - `supabase/config.toml`
  - `supabase/functions/*/index.ts`

### Step 3: Dispatch to specialized sub-skills

Dispatch rules are additive:

1. If Node/Express signals are present, load `unit_test_subskills/security_unit_test_node_express_skill.md`.
2. If Frontend SPA signals are present, load `unit_test_subskills/security_unit_test_frontend_spa_skill.md`.
3. If Supabase signals are present, load `unit_test_subskills/security_unit_test_supabase_baas_skill.md`.

If multiple signals are present, run all matching sub-skills and merge results into one report.

### Step 4: Synthesize and execute

Using shared core + selected sub-skills:

1. Produce/update tests.
2. Run the unit test suite.
3. Write `.ai/blueteam/reports/security_unit_test_coverage.md`.
4. Generate `.ai/blueteam/reports/security_unit_test_coverage.html` via `scripts/generate_report_html.js`.

## Non-negotiable constraints

- Do not add feature code.
- Do not weaken or remove existing tests.
- Respect `@security-test-omit-file` and `@security-test-omit-test` markers.
- Exclude infrastructure-only controls from unit-test scope.

## HTML Report Generation

All `.html` report files are generated by the `generate_report_html.js` script, so do **not** generate HTML manually; run the script instead.

```bash
# Convert the security unit test coverage report:
node <BlueTeam>/scripts/generate_report_html.js --repo-root /path/to/repo
```

Replace `<BlueTeam>` with the path to the BlueTeam skills directory.

## Completion Checklist

Before declaring this skill execution complete, verify every item below.

### Outputs written by this skill

- [ ] Test files written or updated in the repository source tree.
- [ ] Test suite runs without new failures introduced by this skill.
- [ ] `.ai/blueteam/reports/security_unit_test_coverage.md`: written (Step 3).
- [ ] `.ai/blueteam/reports/security_unit_test_coverage.html`: generated by `generate_report_html.js` (Step 4).

### Verification command

```bash
node <BlueTeam>/scripts/validate_reports.js --repo-root /path/to/repo
```

If `validate_reports.js` reports the `.html` file missing, run `generate_report_html.js` before exiting.
